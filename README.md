# Alura - Next.js: Explorando o Framework

Este projeto foi desenvolvido durante o curso "Next.js: Explorando o Framework" da Alura, com o objetivo de aprender e praticar os conceitos fundamentais do Next.js.

## ✨ Tecnologias

- [Next.js](https://nextjs.org/)
- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Font Awesome](https://fontawesome.com/)
- [ESLint](https://eslint.org/)
- [Prettier](https://prettier.io/)

## 🚀 Começando

Primeiramente, você precisa ter o Node.js e o npm instalados em sua máquina.

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/Junior743/alura-nextjs-exploring-the-framework.git
    ```

2.  **Instale as dependências:**

    ```bash
    npm install
    ```

3.  **Inicie o servidor de desenvolvimento:**

    ```bash
    npm run dev
    ```

Abra [http://localhost:3000](http://localhost:3000) em seu navegador para ver o resultado.

## 📜 Scripts Disponíveis

No diretório do projeto, você pode executar:

- `npm run dev`: Inicia o aplicativo em modo de desenvolvimento.
- `npm run build`: Compila o aplicativo para produção.
- `npm run start`: Inicia um servidor de produção.
- `npm run export`: Exporta o aplicativo para HTML estático.
- `npm run lint`: Executa o linter para verificar erros de código.
- `npm run lint:fix`: Corrige automaticamente os erros de lint.

## 📁 Estrutura de Pastas

A estrutura de pastas deste projeto é a seguinte:

```
/
├── public/
│   └── assets/
│       └── images/
└── src/
    ├── components/
    ├── pages/
    └── theme/
```

- **`public`**: Contém todos os arquivos estáticos, como imagens e fontes.
- **`src`**: Contém o código-fonte da aplicação.
  - **`components`**: Contém os componentes React reutilizáveis.
  - **`pages`**: Contém as páginas da aplicação. Cada arquivo nesta pasta se torna uma rota.
  - **`theme`**: Contém os arquivos de estilização e tema da aplicação.
